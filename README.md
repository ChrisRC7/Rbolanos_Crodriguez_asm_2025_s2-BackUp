Al ejecutar el main que se encuentra dentro de la carpeta src se abre una interfaz.

En dicha interfaz se puede introducir manualmente la ecuación de un circulo y de un recta. Tambies esta la opcion de escoger una imagen y que se extraiga de dicha ecuación o ecuaciones que se encuentre. 

En el caso de que no se pueda ver una figura, posiblemente que esta fuera del area de visualización, entonces hay que darle al boton de zoomout hasta que se vea.
